# Exact-version Unity rendering project

Editor: 6000.0.78f1, matching the 1.7.5 Unity asset version.
Universal Render Pipeline: 17.0.4 from this editor's official packages.
Unity UI: 2.0.0, including its official TextMeshPro implementation.
No older UGUI/TMP runtime compatibility forks are included here.

URP is embedded in Packages/com.unity.render-pipelines.universal for the native
renderer port. Its official source and license are preserved. The added
CustomDrawObjectsPass is generated by tools/prepare_native_draw_pass.py;
evidence/native/draw-pass-port.json records hashes and the supporting native
method addresses. CustomRendererRenderGraph replaces the stock opaque and
transparent draws with this MRT pass. Three requested frames and a sixty-frame
continuous session passed GPU checks; evidence/runtime/latest-rendergraph-capture.txt
and latest-interactive-graph.txt identify the outputs. The normal launcher and
Ouvrir-Artikodin-RenderGraph.cmd use the new renderer. The previous builtin mode
is retained in Ouvrir-Artikodin-Diagnostic.cmd.
Batch captures do not prove window presentation or 1:1 visual fidelity.

SourceUiPlan applies the native CardTextView empty-value margin activation and
fontMaterial/UpdateFontAsset sequence. Articuno RR's source-absent fields are
explicitly mapped empty, and serial None skips serial text bindings. No active
RR text binding is unported in the current capture; this does not cover all
UI branches or native text resizing. See evidence/native/card-text-findings.md.

SourceCardShaderState writes the native `_Rotation` property block vector from
the UI loader's zero hologram vector, preserving the dynamic UI textures.
23 renderers and 3 textures pass assertions; three before/after GPU poses are
pixel-identical. This closes an omission without claiming a visual improvement.
See evidence/native/hologram-state-findings.md for native addresses and quality
comparisons. Other scenes and version equivalence remain unverified.

tools/prepare_native_renderer.py stages the matching official orchestration
and changes base-class visibility to allow the native subclass. Its generated
main helper retains camera/prepass/copy stages and replaces forward draw sites.
Group-specific emission/bloom and dynamic modifiers are not fully ported.
The decoded original pipeline scalar settings are applied during the build,
using a strict runtime type-tree decode with all source bytes consumed.
Original reference identities are preserved in decoded-pipeline-settings.json;
stock resources/current global settings are not claimed equivalent to them.

The TMP material registry explicitly includes the uppercase rich-text lookup
hash used by TMP6. The legacy hash alias keeps the old comparison player working.
The source text is preserved, and an integration assertion checks that font
markup is interpreted rather than displayed literally.

Package resolution is recorded in Packages/packages-lock.json. Unity's registry
currently raises some transitive minimum versions (Burst/Collections); the lock
records the actual versions. Their equivalence to the game's dependencies is not
assumed. Matching the editor/package family alone is not proof of fidelity.

The shared card loader, UI plan and original-shader probes are staged by
tools/prepare_native_project.py. The staging manifest records source SHA256s.
Assets still come exclusively from the authorized game's datamine closure.

SourceUiStudio uses the original ScreenSpaceCamera/CanvasScaler configuration.
The native text-quality multiplier is applied to both dynamic UI textures.
The original TMP Settings object is strictly decoded (276 bytes); only script
and two local TextAsset references are relocated into the official envelope.
The TextAsset payloads are unchanged; 35 settings pass runtime comparison.

SourceCardTouch reconstructs Root/Rotation/Parent plus CardBehaviour/Face,
including the native paired 180-degree orientations. Tilt, idle and flip gate
come from ARM64 methods, with acos/acosf verified against ELF imports. The three
original compiled flip AnimationClip payloads are packaged unchanged and played
through Unity's Animator/PlayableGraph. Eight original curve-knot samples and
seven native GPU poses pass. The desktop host rectangle, gyroscope and broader
DGFW touch/animation framework remain partial; no 1:1 claim follows from tests.

Unity's package manager failed because the launch environment lacked
ALLUSERSPROFILE, used by getDeprecatedGlobalConfigRoot in its official app.js.
The build launcher restores its normal Windows CommonApplicationData value
for the child process. No installation or global config file is changed.
